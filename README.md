## Trello Clone

Una aplicación de gestión de tareas inspirada en Trello y desarrollada con React. Este proyecto se centra en crear una interfaz de usuario dinámica e interactiva utilizando prácticas modernas de desarrollo front-end.

Los usuarios pueden organizar tareas en listas, gestionar tarjetas e interactuar con una interfaz de tablero adaptativa, simulando una herramienta de productividad del mundo real.

---

## Características

- Crear y gestionar listas
- Añadir, editar y eliminar tarjetas
- Representación dinámica de estructuras de datos anidadas
- Arquitectura basada en componentes
- Gestión de estado escalable
- Estructura de código limpia y modular

---

## Arquitectura y decisiones técnicas

- Diseño de una estructura de componentes escalable que separa las responsabilidades del tablero, las listas y las tarjetas
- Implementación de un modelo de datos anidado para gestionar las relaciones jerárquicas entre listas y tarjetas
- Uso de los patrones de gestión de estado de React para gestionar de forma eficiente las actualizaciones dinámicas de la interfaz de usuario
- Garantía de la reutilización y el mantenimiento de los componentes mediante un flujo de datos claro y un diseño de props

---

## Stack tecnologico

- React (Vite)
- JavaScript (ES6+)
- CSS / Estilos en línea

---

## Resumen general del proyecto

Este proyecto reproduce la funcionalidad básica de un sistema de gestión de tareas similar a Trello, centrándose en la creación de una interfaz de usuario altamente interactiva y receptiva.

Demuestra la capacidad de gestionar estados complejos, manejar estructuras de datos anidadas y diseñar arquitecturas frontend escalables alineadas con aplicaciones del mundo real.
